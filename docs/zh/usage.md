# 使用方法

[文档目录](README.md) · [English](../en/usage.md)

## 界面布局

```
 PXVIRT │ 节点 · 集群                               SSH / remote   用户   节点 架构   时间
  F1 系统   F2 网络   F3 磁盘   F4 服务日志   F5 PVE                      ← 模块
  1 概览  2 内存  3 进程  ...                                             ← 页面
 ┌ 列表 ───────────────────────────┐ ┌ 详情 ──────────────────┐ ┌ 实时 ┐（宽屏）
 │                                 │ │                        │ │      │
 └─────────────────────────────────┘ └────────────────────────┘ └──────┘
 操作  e 编辑  x 删除  ...                                                ← 本页所有操作
 CPU  内存  网络  磁盘                                ◷ 任务  ● 告警      ← 实时状态
 Esc 返回  Enter 菜单  / 过滤  F6 节点  ? 帮助  Ctrl+Q 退出               ← 按键提示
```

操作栏列出当前选中行的所有操作和对应按键；灰色的表示现在不能执行（打开菜单能看到原因）。

## 按键

| 按键 | 作用 |
|---|---|
| F1 – F5 | 切换模块 |
| 1 – 9、`[` `]` | 切换模块内的页面 |
| Tab、← →（h l） | 在列表和详情之间切换 |
| ↑ ↓（j k）、PgUp PgDn、Home End（G） | 在列表中移动 |
| Enter、`m` | 打开选中项的操作菜单 |
| 字母 | 直接执行操作（见操作栏）；大写 = 强制 / 危险的版本 |
| 空格 | 标记多行，做批量操作 |
| `/` | 过滤列表（Esc 清除） |
| Esc | 返回：详情 → 过滤 → 页面内的子视图（配置页、文件浏览器）→ 标记 |
| `r`、Ctrl+R | 立即刷新（暂停时刷新一次） |
| F7 | 暂停 / 恢复全部刷新，包括实时曲线和状态栏 |
| F6 | 切换节点 |
| F8 | 任务 |
| F10 | 节点的 Shell |
| `g` | 全局菜单：切换节点、暂停、任务中心、告警、语言、Shell、关于、注销 |
| `?` | 帮助 |
| Ctrl+Q | 退出（会确认；系统控制台上禁用） |

图形虚拟机控制台：终端里按 Ctrl+] 打开菜单，tty1 上按 Ctrl+Alt+Shift+Q（发送组合键、切换显示方式、关闭）。

## 鼠标

可以点击模块和页面标签、操作按钮、列表行（双击或右键打开菜单），以及虚拟机的画面预览；滚轮滚动列表和详情。

## 暂停刷新

按 F7 冻结所有刷新：页面数据、实时采样（IO、流量、状态栏）和告警检查。标题栏显示 `⏸ 已暂停 · F7`。暂停时按 `r` 取一次新数据。

## 权限

使用 PVE 账号登录（支持 TFA），按账号的 PVE 权限显示操作，菜单里会说明缺少哪个权限。
主机上的操作（RAID、连接、服务等）需要 `root@pam` 或对应的节点权限，并且需要本机或 SSH 访问。
PVE API 不可用时，`root@pam` 可以用本机密码登录救援模式（PVE 操作走 `pvesh`，只有主机工具可用）。

所有写操作都会记录到节点的 journal（`journalctl -t pxvirt-console`）。

## 语言

支持英文和中文（`--lang` 或全局菜单）。tty1 固定为英文，因为 Linux 控制台没有中文字体。
