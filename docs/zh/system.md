# 系统（F1）

[文档目录](README.md) · [English](../en/system.md)

| 页面 | 显示内容 | 操作 |
|---|---|---|
| 1 概览 | 控制台 / PVE / 系统 / 内核版本；产品、主板、BIOS、启动模式；CPU 型号、拓扑、使用率、负载、虚拟化；内存、Swap、ZFS ARC、KSM；根分区；虚拟机运行数 / 总数；管理地址；CPU 和内存占用最高的进程 | 重启节点 `R`、关闭节点 `S`、按启动顺序启动全部虚拟机 `A`、关闭全部虚拟机 `X`、网络唤醒离线节点 `W` |
| 2 健康 | 硬件优先的健康检查：磁盘 / SMART、内核错误、PCIe、ECC、温度、BMC、网卡、RAID、ZFS / LVM / Ceph、文件系统、服务、时间、证书、集群、备份。见[健康检查](health.md) | 打开相关页面 Enter / `o`、确认 `a`、取消确认 `u`、立即检查 `c` |
| 3 内存 | 内存明细、Swap 设备、swappiness、overcommit、ZFS ARC 大小和上限、大页、透明大页、KSM | 设置 ZFS ARC 上限 `z`、swappiness `w`、大页 `p`、透明大页模式 `T`、启停 KSM `K`、释放页缓存 `d`、刷新 Swap `S` |
| 4 进程 | 全部进程，可排序；虚拟机进程显示为对应的虚拟机 | 结束 `x`（SIGTERM）、强制结束 `X`（SIGKILL） |
| 5 PCI | PCI 设备、驱动、IOMMU 组、链路速率、SR-IOV | 绑定到 vfio-pci `v`、绑定到驱动 `b`、解绑 `u`、恢复默认驱动 `d`、重置 `R`、设置 SR-IOV VF 数 `s`、重新扫描总线 `n` |
| 6 USB | USB 设备和拓扑 | 重置（重新枚举）`R` |
| 7 硬件信息 | `lscpu`、DMI、内存条、传感器（视硬件而定） | – |
| 8 BMC | IPMI 事件日志（完整，最新的在前，带级别；用 `/` 过滤）、BMC 传感器（风扇、电源、电压、温度）、控制器 / LAN / 机箱 / FRU 信息。需要 `ipmitool` 和 `/dev/ipmi0` | 把事件日志导出到 `/var/log/pxvirt-console/` `w`、清空（先导出）`C`、定位灯 `i` / 关闭 `O`、断电恢复策略 `p`、BMC 网络（静态 / DHCP、VLAN）`n`、BMC 冷重启 `R`、安装 ipmitool `I`、加载 IPMI 模块 `M`；切换事件日志 / 传感器 / 信息 `v` |
| 9 更新 | 待更新的软件包、软件包搜索、包详情 | 刷新索引 `u`、全部升级 `U`、升级单个 / 安装 `i`、更新日志 `c`、包信息 `v`、搜索 `s` |
| 10 用户 | PVE 用户、认证域、组、权限 | 修改密码 `p`、重置本机 root 密码 `R`（救援用） |
| 11 证书 | 节点证书及有效期 | 重新生成节点证书 `R` |
| 12 设置 | 时区、本地时间 / UTC、硬件时钟、NTP 服务和同步状态（chrony）、偏差、参考源、配置的 NTP 服务器以及每个源的状态 | 时区 `z`、NTP 服务器 `n`（写入 `/etc/chrony/sources.d/pxvirt-console.sources`；可以停用 `chrony.conf` 里的默认源，会保留备份）、立即同步 `s`、重启 chrony `S`、手动设置日期时间 `t`、写入硬件时钟 `w`、安装 chrony `I` |

危险操作（重启、结束进程、升级、更换驱动）都会确认；最危险的操作需要输入对象名称才能执行。
