# 系统（F1）

[文档目录](README.md) · [English](../en/system.md)

| 页面 | 显示内容 | 操作 |
|---|---|---|
| 1 概览 | 控制台 / PVE / 系统 / 内核版本；产品、主板、BIOS、启动模式；CPU 型号、拓扑、使用率、负载、虚拟化；内存、Swap、ZFS ARC、KSM；根分区；虚拟机运行数 / 总数；管理地址；CPU 和内存占用最高的进程 | 重启节点 `R`、关闭节点 `S`、按启动顺序启动全部虚拟机 `A`、关闭全部虚拟机 `X`、网络唤醒离线节点 `W` |
| 2 内存 | 内存明细、Swap 设备、swappiness、overcommit、ZFS ARC 大小和上限、大页、透明大页、KSM | 设置 ZFS ARC 上限 `z`、swappiness `w`、大页 `p`、透明大页模式 `T`、启停 KSM `K`、释放页缓存 `d`、刷新 Swap `S` |
| 3 进程 | 全部进程，可排序；虚拟机进程显示为对应的虚拟机 | 结束 `x`（SIGTERM）、强制结束 `X`（SIGKILL） |
| 4 PCI | PCI 设备、驱动、IOMMU 组、链路速率、SR-IOV | 绑定到 vfio-pci `v`、绑定到驱动 `b`、解绑 `u`、恢复默认驱动 `d`、重置 `R`、设置 SR-IOV VF 数 `s`、重新扫描总线 `n` |
| 5 USB | USB 设备和拓扑 | 重置（重新枚举）`R` |
| 6 硬件信息 | `lscpu`、DMI、内存条、传感器（视硬件而定） | – |
| 7 更新 | 待更新的软件包、软件包搜索、包详情 | 刷新索引 `u`、全部升级 `U`、升级单个 / 安装 `i`、更新日志 `c`、包信息 `v`、搜索 `s` |
| 8 用户 | PVE 用户、认证域、组、权限 | 修改密码 `p`、重置本机 root 密码 `R`（救援用） |
| 9 证书 | 节点证书及有效期 | 重新生成节点证书 `R` |

危险操作（重启、结束进程、升级、更换驱动）都会确认；最危险的操作需要输入对象名称才能执行。
