## 虚拟机详情

虚拟机的详情分三栏：

- **配置**：CPU、内存、机器类型、BIOS、设备、备注（Tab / ↑ ↓ 滚动）。
- **监控**：状态、运行时间、HA、IP 地址（来自客户机代理 / 容器网卡）、CPU、内存、网络、磁盘，带曲线。每 3 秒采样一次，打开时先用 PVE RRD 里最近一小时的数据填充曲线。
- **控制台画面**（仅虚拟机；需要支持 Kitty / Sixel 图形的终端，tty1 上不显示）：选中虚拟机期间保持一条 VNC 连接，画面大约每秒更新一次。点击画面或按 `v` 打开图形控制台。

punycode 格式（`xn--...`）的名称显示为解码后的中文；在表单里输入的中文名称会自动编码。

## 配置页（`e`）

每个配置项一行，用各自的表单编辑；Esc 返回列表。

- 虚拟机：内存和气球内存、处理器、BIOS、显卡、机器类型、SCSI 控制器、硬盘、光驱、EFI 盘、TPM、网卡、USB、PCI、串口、未使用的磁盘、所有选项、Cloud-Init 和其他配置项。
- 容器：内存 / Swap、核心、rootfs、挂载点、网络、主机名、DNS、特性、选项。
- 需要重启才生效的修改显示为"当前值 → 待生效值"（`u` 撤销）。
- 每次写入都带上配置的 digest：如果别人同时改过配置，PVE 会拒绝这次写入，而不是悄悄覆盖。
- 表单只改自己的字段，设备的其他参数保持不变。
- 添加设备 `+`、分离 / 移除 `x`、删除未使用的卷 `X`、扩容 `R`、迁移磁盘 `M`、弹出光盘 `i`、启动顺序 `o`、编辑原始值 `E`。

## 创建虚拟机 / 容器（`N` / `O`）

集群里会先选节点。每个节点显示架构、CPU 使用率和核数、空闲 / 总内存；默认选中推荐节点（★）：

- 评分 = 空闲内存比例 55% + CPU 空闲 35% + 核数 10%
- 空闲内存不足 2 GiB 的节点排在最后

之后的表单使用所选节点的存储、ISO 和网桥。虚拟机可以加第二个光驱（比如 Windows 用的 virtio-win 驱动 ISO）：x86 上用 `ide2` / `ide0`，其他架构用 `scsi2` / `scsi3`。

## 存储上传（`U`）

从运行控制台的那台机器上传 ISO、CT 模板和导入镜像（OVA / qcow2 / vmdk）：控制台模式下是节点本机，`--ssh` / `--remote` 模式下是你自己的电脑。
上传过程显示进度、速度和剩余时间；Esc 转到后台继续，`x` 取消。可以填写校验值，由 PVE 校验。
节点会先把上传的文件存到 `/var/tmp`，那里需要有足够的空闲空间。
