## 管理网络的保护

修改管理网络时带自动回滚：60 秒内没有确认（比如新地址连不上），systemd 定时器会恢复原来的配置。

## 连接

- `f` 切换 已建立 / 监听 / 全部，`o` 切换按流量 / 进程 / 对端排序。
- 速率来自内核里每个套接字的字节计数（`ss -i`），按两次刷新（2 秒）之间计算。
- 断开连接用 `ss -K`，需要内核支持 `CONFIG_INET_DIAG_DESTROY`，不支持时 `ss` 会报错。
- 需要主机访问（本机或 SSH 模式）。
